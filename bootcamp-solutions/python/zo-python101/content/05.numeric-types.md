# Numeric Types
Python provides several built-in **numeric types** that allow programmers to work with numbers in different forms. These types support arithmetic operations, scientific computing, data analysis, and many other programming tasks.


## What are Numeric Types
A numeric type is a data type designed to store and manipulate a numerical value and allow mathematical operations to be performed on it.

Python has three main built-in numeric types:

1. **int**: Integer numbers
    -  **bool**: subtype of int
2. **float**: Floating-point (decimal) numbers
3. **complex**: Complex numbers

All numeric types in Python are **immutable**, meaning the numeric objects cannot be changed after they are created.

**Example**
```python
x = 5
x = x + 1
```
Python does not modify the original object `5`. Instead, it creates a new object `6`, and `x` references the new object.


## Integer Type (`int`)
Integers are whole numbers without decimal points.

**Example**
```python
a = 10
b = -5
c = 0

# Checking the Type
print(type(a)) # Output: <class 'int'>
print(type(b)) # Output: <class 'int'>
print(type(c)) # Output: <class 'int'>
```

### Features
- No decimal part
- Can be positive, negative, or zero
- Unlimited size (limited only by system memory)


### Integer Number Bases
Python supports multiple number systems for integers.
| Number System | Prefix | Example  |
| ------------- | ------ | -------- |
| Binary        | `0b`   | `0b1010` |
| Octal         | `0o`   | `0o12`   |
| Hexadecimal   | `0x`   | `0xA`    |
| Decimal       |  None    | `10`     |


**Example**
```python
print(0b1010)   # Output: 10
print(0o12)     # Output: 10
print(0xA)      # Output: 10
print(10)       # Output: 10
```

### Useful Integer Methods
#### `bit_length()`
Returns the number of bits required to represent the integer in binary.

**Example** 
```python
x = 10

print(x.bit_length())  # Output: 4
```
The binary representation of `10` is `1010`, which requires 4 bits.

#### `to_bytes()`
Converts an integer into bytes.

**Example** 
```python
result = (65).to_bytes(1, 'big')

print(result) # Output: b'A'
```
- `1` means one byte
- `'big'` specifies byte order, and it refers to big endian.


## Boolean Type (`bool`)
The Boolean type in Python represents **logical values**, with only two possible values: `True` and `False`.

**Example**
```python 
a = True
b = False

# Checking the Type
type(a)    # Output: <class 'bool'>
type(b)    # Output: <class 'bool'>
```
**Booleans are mainly used in:**
- Conditions
- Comparisons
- Decision-making
  
>[!important]
> In Python, boolean values behave like integers (`True` = `1`, `False` = `0`). Boolean is a subtype of integers.

**Example**

```python
print(True + True)    # Output: 2
print(False + 5)      # Output: 5
```


### Truthy and Falsy Values

Some values are automatically treated as `False` in conditions. These are called **falsy values**.

The following values are treated as `False`:
```python
False
0
0.0
0j
''
[]
{}
set()
range(0)
None
```
Everything else is considered **truthy (`True`)**.


### Logical Operators
Logical operators are used to combine or modify conditional expressions.

| Operator | Description                                      | Example            |
| -------- | ------------------------------------------------ | ------------------ |
| `and`    | Returns `True` if both conditions are true       | `x > 5 and y < 10` |
| `or`     | Returns `True` if at least one condition is true | `x > 5 or y < 10`  |
| `not`    | Reverses the truth value                         | `not(x > 5)`       |

**Example**
```python 
x = 10

print(x > 5 and x < 20)    # Output: True
print(x > 15 or x < 20)    # Output: True
print(not(x > 6))          # Output: False
```


## Float Type (`float`)
Floats represent numbers with decimal points.

**Example**
```python
pi = 3.14159
temperature = -2.5

# Checking the Type
print(type(pi))               # Output: <class 'float'>
print(type(temperature))      # Output: <class 'float'>
```

### Features
- Store decimal values
- Support scientific notation
- Can represent very small and very large numbers
- Stored internally in binary format
- May contain precision limitations

### Float Precision Problem
Floating-point numbers may produce small rounding errors because decimal numbers are stored in binary form.

**Example**

```python
print(0.1 + 0.2)   # Output: 0.30000000000000004
```
This is normal behavior in floating-point arithmetic.


### Scientific Notation
Scientific notation is useful for very large or very small numbers.

| Value    | Meaning   |
| -------- | --------- |
| `1.5e3`  | `1500.0`  |
| `2.5e-4` | `0.00025` |


### Special Float Values
Python supports special floating-point values.

#### Positive Infinity
```python 
x = float('inf')
```

#### Negative Infinity
```python
x = float('-inf')
```

#### NaN (Not a Number)
```python
x = float('nan')
```
`NaN` usually appears in invalid mathematical operations.


### Useful Float Methods

#### `is_integer()`
Checks whether the float has no decimal part.

**Example**
```python
result1 = (5.0).is_integer()   
result2 = (3.6).is_integer()   

print(result1)  # Output: True
print(result2)  # Output: False
```


#### `as_integer_ratio()`
Returns the float as a numerator/denominator pair.

**Example** 
```python
result1 = (0.75).as_integer_ratio()   
result2 = (1.50).as_integer_ratio()   


print(result1)  # Output: (3, 4)
print(result2)  # Output: (3, 2)
```

## Complex Type (`complex`)
Complex numbers contain a real part and an imaginary part. Python uses `j` to represent the imaginary part.

**Example**
```python
a = 2 + 3j

# Checking the Type
print(type(a))   # Output: <class 'complex'>
```
- `2`:  real part
- `3j`: imaginary part

### Features
- Cannot be ordered or compared using `<` or `>`
- Useful in scientific and engineering applications

### Accessing Components
```python
x = 4 + 6j

# Real Part
print(x.real)      # Output: 4.0

# Imaginary Part
print(x.imag)      # Output: 6.0
```

### Useful Complex Method

#### `conjugate()`

Returns the complex conjugate.

**Example** 
```python
result = (3 + 4j).conjugate()

print(result)  # Output: (3-4j)
```

##  Type Conversion
Python allows conversion between numeric types.

### Implicit Conversion

Python automatically converts smaller types into larger compatible types during operations.

**Example**

```python
print(5 + 2.0)  # Output: 7.0
```
Python automatically converts the integer `5` into a float `5.0`.


### Explicit Conversion
You can manually convert values using built-in functions.

| Function    | Purpose            |
| ----------- | ------------------ |
| `int()`     | Convert to integer |
| `float()`   | Convert to float   |
| `complex()` | Convert to complex |
| `bool()`    | Convert to Boolean |

**Example**
```python
x = 5

print(float(x))    # Output: 5.0
print(complex(x))  # Output: (5+0j)
print(bool(x))     # Output: True
```

## Number Formatting

Formatting controls how numbers appear when printed.

### Decimal Formatting

```python
price = 49.9876

print(f"{price:.2f}")    # Output: 49.99
```

`.2f` means display digits after the decimal point


### Separating Large Numbers

```python 
number = 9876543210

print(f"{number:,}")     # Output: 9,876,543,210
```
The commas separate the number into groups of three digits, making large values much easier to read.


You can also combine commas with decimal formatting.

```python
price = 1234567.8912

print(f"{price:,.2f}")     # Output: 1,234,567.89
```

## General Operations for All Numeric Types

### Arithmetic Operations

All Python numeric types support arithmetic operations. These operations allow you to perform mathematical calculations using numbers of different types.

| Operator | Description         
| -------- | ------------------- |
| `+`      | Addition            |
| `-`      | Subtraction         |
| `*`      | Multiplication      |
| `/`      | Division            |
| `//`     | Floor division      |
| `%`      | Modulus (remainder) |
| `**`     | Exponentiation      |


**Example**

```python
int1 = 10
int2 = 3

float1 = 5.5
float2 = 2.0

complex1 = 2 + 3j
complex2 = 1 + 2j


print(int1 + int2)           # Output: 13
print(int1 - int2)           # Output: 7
print(float1 * float2)       # Output: 11.0
print(float1 // float2)      # Output: 2.0
print(complex1 / complex2)   # Output: (1.6-0.2j)
print(True + 30)             # Output: 31
print(True ** 5)             # Output: 1
```
> [!note]
> `/`: always returns a float
> 
>`//`: performs floor division


### Comparison Operators

Comparison operators compare values and return a Boolean result.

| Operator | Meaning               |
| -------- | --------------------- |
| `==`     | Equal                 |
| `!=`     | Not equal             |
| `>`      | Greater than          |
| `<`      | Less than             |
| `>=`     | Greater than or equal |
| `<=`     | Less than or equal    |


**Example**
```python 
print(1 > 5)        # Output: False
print(3.5 < 10.2)   # Output: True
print(True == 1)    # Output: True
```

>[!important] 
> Complex numbers only support equality comparisons (`==`, `!=`).


### Assignment Operators

Assignment operators update variable values.

| Operator | Example         | Equivalent To      |
| -------- | --------------- | ------------------ |
| `+=`     | `x += 2`        | `x = x + 2`        |
| `-=`     | `x -= 19.5`     | `x = x - 19.5`     |
| `*=`     | `x *= 2 + 3j`   | `x = x * (2 + 3j)`   |
| `/=`     | `x /= True`     | `x = x / True`     |


### Numeric Functions

Python provides several built-in functions that work with numeric types.

These functions can be used with integers, floats, and sometimes complex numbers, depending on the operation.

| Function   | Description                    |
| ---------- | ------------------------------ |
| `abs()`    | Returns absolute value         |
| `round()`  | Rounds a number                |
| `pow()`    | Raises a number to a power     |
| `max()`    | Returns largest value          |
| `min()`    | Returns smallest value         |
| `divmod()` | Returns quotient and remainder |

**Example**

```python
print(abs(-10))                # Output: 10
print(round(3.14159, 2))       # Output: 3.14
print(pow(2, 3))               # Output: 8
print(max(4, 7, 1))            # Output: 7
print(min(4.5, 2.1))           # Output: 2.1
print(divmod(10, 3))           # Output: (3, 1)
```
