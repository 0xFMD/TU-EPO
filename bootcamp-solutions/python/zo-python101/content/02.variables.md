
# Variables 
Variables are one of the most important concepts in the Python programming language. Most Python programs use variables because they allow programs to store, update, and manipulate data.

## What is a Variable?

A variable is a name that refers to a value stored in memory.

You can think of a variable as a labeled box:

- The **label** is the variable name.
- The **content inside the box** is the value.

**Syntax:**
```python
variable_name = value
```
The operand on the left side of the `=` operator, `variable_name`, is an identifier that refers to the variable, while the operand on the right, `value`, represents the value stored in the variable.

> [!note]
> Python automatically determines the type of data being stored. This means you do not need to specify the data type manually.

**Example:**

```python 
age = 30
city = "Riyadh"
price = 19.99
```

- The variable `age` now stores the number `30`.
- The variable `city` now stores the text `Riyadh`.
- The variable `price` now stores the floating-point number `19.99`.

You can display variable values using `print()`.

```python
print(age)
print(city)
print(price)
```

**Output:**
```python
30
Riyadh
19.99
```

## Multiple Assignment

Python allows you to assign multiple variables in a single line.

**Example:**
```python
x, y, z = 1, 2, 3
```
This means:

```python
x = 1
y = 2
z = 3
```

The values are assigned to the variables in the same order.


## Assigning Same Value to Multiple Variables

You can define multiple variables with the same value on a single line.

**Example:** 
```python
a = b = c = 100
```

This means all three variables store the value `100`.


## Rules for Naming Variables

Python has specific rules for variable names. Following these rules is very important.

#### 1. Variable names can contain letters (`a-z`, `A-Z`), numbers (`0-9`), and underscores (`_`)
**Example:** 
```python
user_name = "Ali"
age2 = 30
```


#### 2. Variable names can't start with a number
**Example:**
```python
2name = "Ali" # Incorrect
name2 = "Ali" # Correct
```

#### 3. Variable names can't contain spaces
**Example:**
```python
first name = "Sara" # Incorrect
first_name = "Sara" # Correct
```
>[!tip]
> #### Use the snake_case style
> Python programmers typically write variable names in lowercase with underscores. This naming convention is recommended by Python's official style guide (PEP 8).


#### 4. Variable names can't contain special characters

**Example:**
```python
price$ = 100   # Incorrect
price = 100    # Correct
```

#### 5. Variable names can't use Python keywords
Keywords such as `if`, `for`, `class`, and `def`  are reserved words that have special meanings in Python.

**Example:** 
```python
class = "Math"  # Incorrect
course = "Math" # Correct
```


## Variables are Case-Sensitive
Python variable names are case-sensitive.

**Example:** 

```python
age = 20
print(age)

Age = 30
print(Age)
```

**Output:**
```python
20
30
```

The variables `age` and `Age` are different from each other.


## Changing Variable Value

The value of the variable can change during program execution.

**Example:** 

```python
score = 50
print(score)

score = 80
print(score)
```

**Output:**
```python
50
80
```

The new value replaces the old one.

### Dynamic Typing

Python allows a variable to reference values of different types.

**Example:**
```python 
x = 10
print(x)

x = "Hello"
print(x)
```

**Output:**
```python
10
Hello
```
The variable `x` first stores a number and later stores a text.


This flexibility is called **dynamic typing**. However, beginners should avoid changing variable types too often because it can make programs harder to understand.

## Print Variables Using f-Strings

**f-strings** (also called **formatted string literals**) are a feature in Python that makes it easy to insert variables, expressions, function calls, and formatted values directly into a string. They were introduced in **Python 3.6**.

#### Syntax
- Add the letter **`f`** before the opening quotation mark to tell Python that the string is a formatted string literal.
- Anything inside **`{}`** is evaluated and replaced with its value.

**Example:**
```python
first_name = "Sara"
last_name = "Ahmad"
age = 20


print(f"My name is {first_name} {last_name}.")
print(f"I am {age} years old.")
print(f"Next year I will be {age + 1} years old.")
```

**Output:**
```
My name is Sara Ahmad.
I am 20 years old.
Next year I will be 21 years old.
```

## Deleting Variables
You can remove a variable using `del`.

**Example:**
```python
x = 100
del x
```
Trying to use `x` after deleting it will produce an error.
