# Sequence Types
Python provides several built-in **sequence types** that allow programmers to store and organize multiple values in a specific order. Sequence types are widely used because they make it easy to work efficiently with groups of related data.


## What are Sequence Types
A sequence type is a data type that stores multiple items in a specific order. Each item in a sequence has a position called an **index**.

Python includes several built-in sequence types:

1. **list**: Mutable ordered collection
2. **tuple**: Immutable ordered collection
3. **range**: Immutable sequence of numbers
4. **str**: Immutable sequence of characters

## Common Features of Sequence Types
Most sequence types support:

- Indexing: Accessing a single item using its position.
> [!important]
> Python indexing starts from `0`, not `1`.
- Slicing: Extracting part of a sequence.
- Membership testing: Checking whether a value exists inside a sequence.
- Iteration: Looping through sequence items.


## List Type (`list`)
Lists are **ordered, mutable collections** that can store multiple values of the same or different data types using `[]` brackets.

**Example**
```python
numbers = [1, 2, 3]
mixed = [10, "Python", True, 3.5]

# Checking the type
print(type(numbers))   # Output: <class 'list'>
print(type(mixed))     # Output: <class 'list'>
```

### Features
- Ordered collection
- Mutable (can be modified after creation)
- Allows duplicate values
- Can store different data types


### Accessing List Elements

```python
colors = ["red", "green", "blue"]

print(colors[0])    # Output: red
print(colors[2])    # Output: blue
print(colors[-1])   # Output: blue
print(colors[-2])   # Output: green
```
All sequences in Python support both positive and negative indexing.
- **Positive indexing**: starts at the beginning of the sequence with `0`.
- **Negative indexing**: starts at the end of the sequence with `-1`.

In the colors list:

| Value | Positive index | Negative index |
|-------|:--------------:|:--------------:|
| red	  |     0          |     -3         |
| green |     1          |     -2         |
| blue  |	    2          |	   -1         | 


### Modifying Lists
Because lists are mutable, their items can be changed after creation.
```python
colors = ["red", "green", "blue"]
colors[1] = "yellow"

print(colors)   # Output: ["red", "yellow", "blue"]
```

### Useful List Methods

#### `append()`

Adds an item to the end of the list.

**Example**
```python
colors = ["red", "green", "blue"]

colors.append("yellow")

print(colors)   # Output: ['red', 'green', 'blue', 'yellow']
```

#### `remove()`

Removes the first matching item.

**Example**

```python
colors = ["red", "green", "blue", "green"]

colors.remove("green")

print(colors)   # Output: ['red', 'blue', 'green']
```

#### `sort()`

Sorts the list in ascending (alphabetical) order.

**Example**

```python
colors = ["red", "green", "blue"]

colors.sort()

print(colors)   # Output: ['blue', 'green', 'red']
```

#### `reverse()`

Reverses the current order of the list elements.

```python
colors = ["red", "green", "blue"]

colors.reverse()

print(colors)   # Output: ['blue', 'green', 'red']
```

## Tuple Type (`tuple`)

Tuples are **ordered, immutable collections**, meaning they cannot be changed after creation. Tuples use `()` brackets.

**Example**

```python
numbers = (10, 20)
single = (5,)

# Checking the Type
print(type(numbers))   # Output: <class 'tuple'>
print(type(single))        # Output: <class 'tuple'>
```
> [!important]
> A comma is required for single-item tuples.


### Features
- Ordered collection
- Immutable (cannot be modified)
- Allows duplicate values
- Faster than lists for fixed data


### Accessing Tuple Elements

```python
data = ("Python", 3.12, True)

print(data[0])   # Output: Python
print(data[-1])  # Output: True
```

### Useful Tuple Methods

#### `count()`

Returns the number of occurrences of a value.

**Example**
```python
letters = ("a", "b", "a", "c")

print(letters.count("a"))   # Output: 2
```

#### `index()`

Returns the position of a value.

**Example**

```python
letters = ("a", "b", "c")

print(letters.index("b"))   # Output: 1
```



## Range Type (`range`)

`range` represents an **immutable sequence of numbers**.

A range object is not directly displayable. Therefore, ranges are often converted to lists for display.


### Range Syntax
```python
range(start, stop, step)
```

|Parameter|	Description|
|---------|-----------|
| `start` |	(Optional) First value in the sequence. The default value is `0`|
| `stop ` |	(Required) The sequence should end before this value by 1|
| `step`  |	(Optional) The difference between each number. The default value is `1`|

**Example**
```python
range1 = range(5)        # starts at 0, stops before 5, increments by 1
range2 = range(1, 5)     # starts at 1, stops before 5, increments by 1
range3 = range(1, 5, 2)  # starts at 1, stops before 5, increments by 2

print(list(range1))   # Output: [0, 1, 2, 3, 4]
print(list(range2))   # Output: [1, 2, 3, 4]
print(list(range3))   # Output: [1, 3]
```

### Features
- Immutable sequence
- Efficient memory usage
- Commonly used with loops

### Accessing Values

```python
numbers = range(10)

print(numbers[3])   # Output: 3
print(numbers[-1])  # Output: 9
```


## String Type (`str`)

Strings are sequences of characters used to store text.

**Example**

```python
word = "Python"

# Checking the type
print(type(word))   # Output: <class 'str'>
```

### Features
- Immutable sequence
- Ordered collection of characters
- Store text data
- Supports many text-processing methods


### Accessing Characters

```python
word = "Python"

print(word[0])   # Output: P
print(word[-2])  # Output: o
```

### Useful String Methods

#### `upper()`

Converts all characters to uppercase.

**Example**
```python
word = "Python"

print(word.upper())   # Output: PYTHON
```

#### `lower()`

Converts all characters to lowercase.

**Example**

```python
word = "Python"

print(word.lower())   # Output: python
```

#### `replace()`

Replaces part of a string.

**Example**

```python
text = "I like Java"

print(text.replace("Java", "Python"))   # Output: I like Python
```

## Common Sequence Operations

Most sequence types support several common operations.


### Slicing
Slicing extracts part of a sequence.

**Syntax**
```python
sequence[start:stop:step]
```
- `start`: Starting index (inclusive). The default value is 0.
- `stop`: Index where slicing stops before it. The default value is the end of the sequence.
- `step`: Number of positions to move between items. The default value is 1.

**How it works:**
```python
text = "Python"

print(text[1:4:2])   # Output: yh
```
- Start at index 1 (y)
- Stop before index 4 (o)
- Move 2 positions at a time


**Example** 
```python
# List
fruits = ["apple", "banana", "cherry", "orange"]
print(fruits[1:3])    # Output: ['banana', 'cherry']

# Tuple
numbers = (6, 8, 5, 0)
print(numbers[:2])     # Output: (6, 8)
print(numbers[:-1])    # Output: (6, 8, 5)

# Range
values = range(7)
print(list(values[1:]))    # Output: [1, 2, 3, 4, 5, 6]
print(list(values[-3:]))   # Output: [4, 5, 6]


# String
text = "Python"
print(text[::2])   # Output: Pto
```

| Slice    | Meaning                                            |
| -------- | -------------------------------------------------- |
| `[1:3]`  | Start at index `1` and stop before index `3`       |
| `[:2]`   | Start from the beginning and stop before index `2` |
| `[:-1]`  | Get all items except the last one                  |
| `[1:]`   | Start at index `1` and continue to the end         |
| `[-3:]`  | Get the last three items                           |
| `[::2]`  | Select every second item                           |
| `[::-1]` | Reverse the sequence                               |


### Concatenation

Joining sequences together.

```python
# List
numbers1 = [1, 2]
numbers2 = [3, 4]
print(numbers1 + numbers2)   # Output: [1, 2, 3, 4]


# Tuple
numbers1 = (1, 2)
numbers2 = (3, 4)
print(numbers1 + numbers2)   # Output: (1, 2, 3, 4)


# String
text1 = "Py"
text2 = "thon"
print(text1 + text2)   # Output: Python
```
> [!note]
> `range` objects do not support concatenation using `+`.


### Repetition

Repetition duplicates sequence contents.

```python
print("Hi " * 3)   # Output: Hi Hi Hi

print([1, 2] * 2)   # Output: [1, 2, 1, 2]

print((1, 2) * 3)   # Output: (1, 2, 1, 2, 1, 2)
```
> [!note]
> `range` objects do not support repetition using `*`.


### Membership Operators

Checking whether a value exists in a sequence.

| Operator | Description                            |
| -------- | -------------------------------------- |
| `in`     | Returns `True` if value exists         |
| `not in` | Returns `True` if value does not exist |

**Example**

```python
# List
numbers = [1, 2, 3]
print(2 in numbers)          # Output: True

# Tuple
data = ("Python", "Java")
print("C++" not in data)     # Output: True

# Range
values = range(5)
print(6 in values)           # Output: False

# String
text = "Python"
print("th" not in text)      # Output: False
```

### Built-in Functions for Sequences

Python provides several built-in functions that work with all sequence types.

| Function     | Description                    |
| ------------ | ------------------------------ |
| `len()`      | Returns number of items        |
| `max()`      | Returns largest item           |
| `min()`      | Returns smallest item          |
| `sum()`      | Returns total of numeric items |

> [!important]
> `sum()` only works with numeric values. Using it with strings or characters raises a TypeError.

**Example**
```python
# len()
print(len([1, 2, 3]))          # Output: 3
print(len("Python"))           # Output: 6

# max()
print(max([3, 7, 1]))          # Output: 7
print(max(range(5)))           # Output: 4

# min()
print(min((5, 2, 9)))          # Output: 2
print(min("Python"))           # Output: P

# sum()
print(sum([1, 2, 3]))         # Output: 6
print(sum(range(5)))          # Output: 10
```
>[!note]
> For strings, `max()` and `min()` compare characters using their Unicode values (uppercase letters have different Unicode values than lowercase letters.).



### Sequence Packing and Unpacking

Python allows multiple values in a sequence to be grouped together or assigned to separate variables easily.
- **Packing**: Storing multiple values into a single sequence
- **Unpacking**: Extracting values from a sequence into variables

This works with all sequence types.

**Example**

#### packing
```python
# List
my_list = [1, 2, 3]

# Tuple 
my_tuple  = (10, 20)

# Range
my_range = range(1, 4)

# String
my_string = "cat"
```

#### Unpacking
```python
# List 
a, b, c = [1, 2, 3]

print(a)   # Output: 1
print(b)   # Output: 2
print(c)   # Output: 3

# Tuple 
a, b = (10, 20)

print(a)   # Output: 10
print(b)   # Output: 20

# Range
a, b, c = range(1, 4)

print(a)   # Output: 1
print(b)   # Output: 2
print(c)   # Output: 3


# String
a, b, c = "cat"

print(a)   # Output: c
print(b)   # Output: a
print(c)   # Output: t

```

> [!important]
> Unpacking requires the correct number of variables. Using more or fewer variables than sequence items causes a `ValueError`.


#### Using `*` for Remaining Values

The `*` operator collects remaining values into a list.

```python
first, *middle, last = [10, 20, 30, 40, 50]

print(first)    # Output: 10
print(middle)   # Output: [20, 30, 40]
print(last)     # Output: 50
```
