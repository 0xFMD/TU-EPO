# Loops in Python

Loops are used to **repeat a block of code multiple times**.

Python provides two main types of loops:

- `for` loop  
- `while` loop  

Loops help reduce repetitive code and make programs more efficient.



## `for` Loop

The `for` loop is used to iterate over a sequence such as a list, string, tuple, and range.

- Syntax

```python
for variable in sequence:
    # code to repeat
```



- Examples

Loop through a list:

```python
fruits = ["Apple", "Banana", "Orange"]

for fruit in fruits:
    print(fruit)
```

Output
```
Apple
Banana
Orange
```

Loop through a range:
```python
for i in range(5):
    print(i)
```
`range(5)` generates numbers starting from 0 up to 5 - 1.

Output
```
0
1
2
3
4
```

##  `while` Loop

The `while` loop repeats as long as a condition is `True`.

- Syntax

```python
while condition:
    # code to repeat
```


- Example

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output
```
1
2
3
4
5
```

> [!Important]
> Make sure the condition eventually becomes `False`, otherwise you create an **infinite loop**.


## Loop Control Statements

Python provides special statements to control loops.



### `break`

Stops the loop immediately.

- Example

```python
for i in range(5):
    if i == 3:
        break
    print(i)
```

Output
```
0
1
2
```


### `continue`

Skips the current iteration and moves to the next one.

- Example

```python
for i in range(5):
    if i == 3:
        continue
    print(i)
```

Output
```
0
1
2
4
```

### `else` 
Runs only if the loop completes normally (without hitting `break`).  

- Example

```python
i = 1
while i < 6:
  print(i)
  i += 1
else:
  print("i is no longer less than 6")
```

Output
```
1
2
3
4
5
i is no longer less than 6
```


## `for` vs `while`

| for Loop | while Loop |
|-----------|------------|
| Used when you know the number of iterations | Used when condition controls repetition |
| Iterates over a sequence | Runs while condition is true |
