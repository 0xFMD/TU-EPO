# Functions

A function is a **block of reusable code** that performs a specific task.

Functions help:
- Organize code
- Avoid repetition
- Make programs easier to read and maintain

### Types of Functions
There are two main types of functions:
- Built-in functions.
- User-defined functions.


## Built-in Functions
Built-in functions are functions that Python provides automatically. You do not need to create them, they are already available to be used directly.

Such as:
- `print()`
- `input()`
- `len()`
- `type()`


### `input` Function
`input()` is a function used to request input from the user, it always returns data as a string.
- Syntax
```python
input()
```
- Example
```python
name = input("Enter your name: ")
print("Hello", name)
```
>[!note]
> `name` is the variable that stores the user’s input, and the text inside the parentheses is called a prompt (a hint for the user).


Output
```
Enter your name: Abdullah
Hello Abdullah
```

## User-defined Function
User-defined functions are functions that you create yourself using the `def` keyword.

### Defining a Function

- Syntax

```python
def function_name():
    # code block
```

- Example

```python
def greet():
    print("Hello, welcome to Python!")
```

To run a function, you must **call it**:

```python
greet()
```

Output
```
Hello, welcome to Python!
```

### Functions with Parameters

Parameters allow you to pass data into a function.

- Syntax

```python
def function_name(parameter):
    # code
```

- Function with one parameter

```python
def greet(name):
    print("Hello", name)
```

Calling the function:

```python
greet("Abdullah")
```

Output
```
Hello Abdullah
```


- Function with multiple parameters

```python
def add(a, b):
    print(a + b)
```

```python
add(5, 3)
```

Output
```
8
```


### Return Statement

Functions can return values using the `return` keyword.

- Syntax

```python
def function_name():
    return value
```

- Example

```python
def add(a, b):
    return a + b
```

```python
result = add(5, 3)
print(result)
```


Output
```
8
```

You can use the returned value directly

```python
def add(a,b):
  return a+b

print(add(5,6))
```


>[!note]
>`return` sends the result back to where the function was called. 

### Important Behavior of `return`

1. `return value` sends the value back and exits the function immediately

- Example
```python
def example():
    print("Start")
    return
    print("End")   # This will NOT run

example()
```
Output
```
Start
```

2. If there is no `return` Statement

If a function does not use `return`, it ends after the last statement and continues the execution after the function call. 

- Example

```python
def info():
    print("Hello")

info()
print("Ali")
```

Output
```
Hello
Ali
```
### Default Parameters

You can assign default values to parameters.

```python
def greet(name="Guest"):
    print("Hello", name)
```

```python
greet()
greet("Sara")
```

Output
```
Hello Guest
Hello Sara
```

## Keyword Arguments

Keyword arguments allow you to specify which value belongs to which parameter.

- Syntax

```python
function_name(parameter=value)
```

- Example
```python
def introduce(name, age):
    print("Name:", name)
    print("Age:", age)

introduce(age=25, name="Sara")
```
Now:
- The order does **not** matter  
- The code is more readable  
- Each value is clearly matched to its parameter  

### When Should you use Keyword Arguments?

Use them when:

- A function has multiple parameters  
- The argument order might be confusing  
- You want clearer and more readable code  

## Important Rules about Functions
- Functions must be defined before they are called.</br>
- A function runs only when it is called.</br>
- Use indentation (4 spaces) inside functions.  </br>
