# Set Types

Python provides built-in **set types** that allow programmers to store collections of unique values. Sets are useful when you need to eliminate duplicates, perform mathematical set operations, or efficiently test whether a value exists in a collection.

Unlike sequence types, set types are **unordered**, meaning their items do not have fixed positions.


## What are Set Types

A set type is a data type that stores **unique immutable values without a fixed order**.

Python includes two built-in set types:

1. **set**: Mutable collection of unique values
2. **frozenset**: Immutable collection of unique values

## Features of Set Types

- Membership testing: Checking whether a value exists in a set.
- Iteration: Looping through set items.
- Set operations: Union, intersection, difference, and symmetric difference.
- Automatic duplicate removal.

> [!important]
> Sets do not support indexing or slicing because they are unordered collections.


## Set Type (`set`)

Sets are **unordered, mutable collections** that store unique values. They are defined using curly braces `{}`.

**Example**

```python
numbers = {1, 2, 3}
mixed = {10, "Python", True, 3.5}

# Checking the type
print(type(numbers))   # Output: <class 'set'>
print(type(mixed))     # Output: <class 'set'>
```

> [!important]
> Empty braces `{}` create a dictionary, not a set. Use `set()` to create an empty set.

```python
empty_set = set()

print(type(empty_set))   # Output: <class 'set'>
```

### Features

- Unordered collection
- Mutable (can be modified after creation)
- Does not allow duplicate values
- Can store different data types
- Fast membership testing


### Duplicate Removal

Sets automatically remove duplicate values.

```python
numbers = {1, 2, 2, 3, 3, 3}

print(numbers)   # Output: {1, 2, 3}
```

### Accessing Set Values

Sets do not support indexing because they are unordered.

```python
colors = {"red", "green", "blue"}

# print(colors[0])   # Error
```

To access set values, use loops.

```python
colors = {"red", "green", "blue"}

for color in colors:
    print(color)
```

> [!note]
> The order of set items may appear different each time the program runs.


### Useful Set Methods
Since sets are mutable, items can be added or removed after creation.

#### `add()`

Adds a single item to the set.

**Example**

```python
colors = {"red", "green"}

colors.add("blue")

print(colors)   # Output: {'red', 'green', 'blue'}
```

#### `update()`

Adds multiple items to a set.

**Example**

```python
colors = {"red", "green"}

colors.update(["blue", "yellow"])

print(colors)   # Output: {'blue', 'yellow', 'green', 'red'}
```

#### `remove()`

Removes a specified item.

**Example**

```python
colors = {"red", "green", "blue"}

colors.remove("green")

print(colors)  # Output: {'red', 'blue'}
```

> [!important]
> `remove()` causes an error if the item does not exist.


#### `discard()`

Removes a specified item if it exists.

**Example**

```python
colors = {"red", "green", "blue"}

colors.discard("green")
colors.discard("yellow")

print(colors)   # Output: {'red', 'blue'}
```

Unlike `remove()`, `discard()` does not raise an error if the item is missing.

#### `clear()`

Removes all items from the set.

**Example**

```python
colors = {"red", "green", "blue"}

colors.clear()

print(colors)   # Output: set()
```

### Subset and Superset

A set is a **subset** if all of its elements exist in another set.

```python
set1 = {1, 2}
set2 = {1, 2, 3}

print(set1.issubset(set2))  # Output: True
```
A set is a **superset** of another set if it contains all its elements.
```python
set1 = {1, 2}
set2 = {1, 2, 3}

print(set2.issuperset(set1))   # Output: True
```

## Frozen Set Type (`frozenset`)

A `frozenset` is an **immutable version of a set**. Once created, its contents cannot be changed.

**Example**

```python
numbers = frozenset([1, 2, 3])

# Checking the Type
print(type(numbers))   # Output: <class 'frozenset'>
```

### Attempting Modification

```python
numbers = frozenset([1, 2, 3])

numbers.add(4)   # Output: AttributeError: 'frozenset' object has no attribute 'add'
```

>[!note]
> Frozensets are immutable, meaning you cannot add or remove elements. However, they support all non-mutating operations of sets.



## Common Set Operations

Set types support mathematical operations for comparing and combining collections.

### `copy()`

Creates a copy of a set.

**Example**

```python
numbers = {1, 2, 3}
new_numbers = numbers.copy()
print(new_numbers)          # Output: {1, 2, 3}


letters = frozenset(["a", "b", "c"])
copy_letters = letters.copy()
print(copy_letters)         # Output: frozenset({'c', 'a', 'b'})
```

### `isdisjoint()`

Returns `True` if two sets have no common elements.

**Example**

```python
set1 = {1, 2, 3}
set2 = {4, 5, 6}
print(set1.isdisjoint(set2))   # Output: True


frozenset1 = frozenset([1, 2, 3])
frozenset2 = frozenset([4, 5, 6])
print(frozenset1.isdisjoint(frozenset2))   # Output: True
```

### Union

Combines all unique values from both sets.

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

print(set1 | set2)   # Output: {1, 2, 3, 4, 5}
```

This is equivalent to:

```python
print(set1.union(set2))    # Output: {1, 2, 3, 4, 5}
```


### Union Assignment (|=)

The union assignment operator combines another set with the current set and stores the result in the original set.

```python
set1 = {1, 2}
set2 = {3, 4}

set1 |= set2

print(set1)  # Output: {1, 2, 3, 4}
```

This is equivalent to:

```python
set1.update(set2)
```

### Intersection

Returns values that exist in both sets.

```python
set1 = {1, 2, 3}
set2 = {2, 3, 4}

print(set1 & set2)   # Output: {2, 3}
```

This is equivalent to:

```python
print(set1.intersection(set2))   # Output: {2, 3}
```

### Difference

Returns values found only in the first set.

```python
set1 = {1, 2, 3}
set2 = {2, 4}

print(set1 - set2)   # Output: {1, 3}
```

This is equivalent to:

```python
print(set1.difference(set2))    # Output: {1, 3}
```

### Symmetric Difference

Returns values that exist in only one of the sets.

```python
set1 = {1, 2, 3}
set2 = {2, 4}

print(set1 ^ set2)   # Output: {1, 3, 4}
```

This is equivalent to:

```python
print(set1.symmetric_difference(set2))  # Output: {1, 3, 4}
```

### Membership Operators

Checking whether a value exists in a set.

| Operator | Description                            |
| -------- | -------------------------------------- |
| `in`     | Returns `True` if the value exists         |
| `not in` | Returns `True` if the value does not exist |

**Example**

```python
numbers = {1, 2, 3}

print(2 in numbers)        # Output: True
print(5 not in numbers)    # Output: True
```
