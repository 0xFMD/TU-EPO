
# Conditional Statements in Python

Conditional statements allow Python to make decisions based on conditions.

Python uses:
- `if`
- `elif`
- `else`
- `match`

These statements control the flow of a program.

# `if` Statement

The `if` statement executes a block of code **only if the condition is `True`**.

- Syntax
```python
if condition:
    # code to execute
```

> [!IMPORTANT]
> Python uses **indentation (spaces or tabs)** to define nested blocks of code, unlike languages that use `{}`.

```python
if True:
    print("Hello")
```

The indented line belongs to the if block. If indentation is incorrect, Python will raise an `IndentationError`.

>[!important]
> Use 4 spaces per indentation level.


- Example

```python
age = 18

if age >= 18:
    print("You are an adult.")
```

Output
```
You are an adult.
```

# `if`-`else` Statement

Used when you want one block to run if the condition is `True`, and another if it is `False`.

- Syntax
```python
if condition:
    # runs if True
else:
    # runs if False
```

- Example

```python
number = 5

if number %2 == 0:
    print("Even number")
else:
    print("Odd number")
```

Output
```
Odd number
```

# `if`-`elif`-`else` Statement

Used when checking **multiple conditions**.
- Syntax
```python
if condition1:
    # block 1
elif condition2:
    # block 2
else:
    # block 3
```

- Example

```python
score = 75

if score >= 90:
    print("Grade A")
elif score >= 70:
    print("Grade B")
elif score >= 50:
    print("Grade C")
else:
    print("Fail")
```

Output
```
Grade B
```

# Logical Operators

Logical operators allow you to combine multiple conditions.

| Operator | Meaning | Example |
|-----------|----------|-----------|
| `and` | Both conditions must be `True` | `age >= 18 and has_license` |
| `or` | At least one condition must be `True` | `age >= 18 or is_student` |
| `not` | Reverses the condition | `not has_license` |

- Example
```python
age = 20
has_license = True

if age >= 18 and has_license:
    print("You can drive.")
```

Output

```
You can drive.
```

# `match` Statement
The `match` statement is used for pattern matching, it provides a clean and structured way to compare a single expression against multiple possible values.
- Syntax
```python
match expression:
    case value1:
        # block 1
    case value2:
        # block 2
    case _:
        # default case
```
> The underscore _ represents the default case (like else).

- Example
```python
number = 2

match number:
    case 1:
        print("One")
    case 2:
        print("Two")
    case 3:
        print("Three")
    case _:
        print("Unknown number")
```
Output
```python
Two
```
- You can match multiple values using `|` (OR operator).
```python
day = "Saturday"

match day:
    case "Saturday" | "Sunday":
        print("Weekend")
    case _:
        print("Weekday")
```
Output
```python
Weekend
```
- You can add conditions using `if` inside a case.

```python
age = 20

match age:
    case age if age >= 18:
        print("Adult")
    case _:
        print("underage")
```
Output
```python
Adult
```

#### When to use `match` instead of `if`?
Use `match` when:
- Comparing one variable against many specific values
- Replacing long `if–elif` chains
- Writing cleaner and more structured decision logic

Use `if` when:
- Working with ranges (>, <, >=)
- Combining logical operators
- Writing complex conditions
