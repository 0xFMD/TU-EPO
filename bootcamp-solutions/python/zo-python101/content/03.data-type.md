# Data Type 

Python is a dynamically typed programming language, meaning that you do not need to declare the type of a variable explicitly. Instead, types are assigned to values at runtime. Python organizes these types into a hierarchy, and many types share common behaviors. 


## Data Types in Python
In Python, a data type is not just a classification of values, it is actually a **template** (class) that defines what kind of information is stored and how it behaves. **When we use a data type, we create a value based on that template** (an instance of the class). 

This means:
- Every value is an **object**
- Every object has a **type**
- That type defines:
  - What data does the object store
  - What operations does it support
  - What methods does it provide

That includes:
* numbers (`10`, `3.14`)
* text (`"hello"`)
* collections (`[1, 2, 3]`)
* functions


**Example:**
```python
x = 10
```
- Even though it looks like just a number, `10` is actually an object of type `int`. (integer). It has built-in methods like `.bit_length()`, `.to_bytes()`, etc.


## What does object mean

An object is a  combination of:

- **data**: value stored in memory
- **behavior**: methods and operations available for that value

>[!note]
> Different object types provide different methods and behaviors.


### Every Python object has three important properties:

**1. Identity**

The object's unique identity during its lifetime.

```python
a = 10
print(id(a))
```

> `id()` returns the identity of the object.


**2. Type**

The category or class of the object.

```python
type(a)
```

Output:

```python
<class 'int'>
```


**3. Value**

The actual data stored inside the object.

```python
a = 10
```

The value is `10`

>[!tip]
> #### Think of Python like this:
> - Everything = object
> - Object = box containing:
>   - Value (data)
>    - Type (what it is)
>    - Methods (what it can do)

## Python Data Type Categories 

Python groups built-in data types into **families (categories)** based on how they store and organize data.

The most important ones are:

- Numeric Types
- Sequence Types
- Mapping Type
- Set Types
- None Type

Each data type category has its own subtypes, which behave differently and solve different kinds of problems.

For example:

- Strings, lists, and tuples are all **sequence types**.
- Integers and floating-point numbers are **numeric types**.

These types follow specific **protocols**. A **protocol** is a collection of behaviors or methods that an object supports.

For example, sequence types support:
- Indexing
- Iteration
- Length checking



## Numeric Types

**Numeric types represent single values that are numbers.** They are used for calculations, math operations, and measurements.

In Python, numeric types are:
- `int`
- `float`
- `complex`


### Properties of Numeric Types
- store **a numeric value**
- You cannot modify the number in place.
- Used for computation


### Operations Supported by Numeric Types

- Arithmetic Operators
- Bitwise Operators



## Sequence Types

**Sequence types store an ordered collection of items.** Items are stored in a specific order and can be accessed by index.

In Python, Sequence types are:
- `list`
- `tuple`
- `str`
- `range`

### Properties of Sequence Types
- Ordered
- Support indexing and slicing
- Iterable
- Can store multiple values
- Can store mixed data types



### Operations Supported by Sequence Types
- Indexing
- Slicing
- Concatenation
- Repetition
- Membership testing 



## Set Type

**A set is an unordered collection of unique values** where duplicate values are automatically removed.

In Python, the set types are:
- `set`
- `frozenset`

### Properties of Set Types
- Stores only unique values
- Unordered collection
- Can store multiple data types
- Fast membership testing
- Duplicates are automatically removed
- Iterable


### Operations Supported by Set Types
- Union
- Intersection
- Difference
- Symmetric Difference



## Mapping Type

**A mapping type stores data as key–value pairs.** Instead of positions (like sequences), you access values using a **key**.

In Python, the main mapping type is:

- `dict` (dictionary)


### Properties of Mapping Type
- Stores data as key-value pairs
- Keys must be unique
- Keys cannot change
- Fast lookups
- Highly flexible


### Operations Supported by Mapping Type

- get
- keys
- values
- items
- update

## None Type

**The None type represents the absence of a value.** It is used when a variable has no value or when a function does not return anything.

In Python, the None type is:

- `NoneType`


### Properties of None Type

- Represents "no value"
- Has only **one possible value** which is `None`
- Commonly used as a default value
- If a function doesn't return a specific value, it will return `None` by default
- Different from `0`, `False`, or empty strings

### Operations Supported by None Type
- Checks identity
- Truth-value testing


## Type Conversion

Python allows converting values between types.

### Common Conversion Functions

| Function  | Purpose            |
| --------- | ------------------ |
| `int()`   | Convert to integer |
| `float()` | Convert to float   |
| `str()`   | Convert to string  |
| `list()`  | Convert to list    |
| `tuple()` | Convert to tuple   |
| `set()`   | Convert to set     |
| `bool()`  | Convert to Boolean  |
| `dict()`  | Converts a sequence of key-value pairs|


**Examples:**
- int to float
```python
float(5)  # 5.0
```

- float to int
```python
int(3.9)  # 3
```

- string to int
```python
int("100")  # 100
```


## Mutability in Python

Mutability describes whether an object can be changed after creation.

### Mutable Types
These objects can be modified in place:

- `list`
- `dict`
- `set`
- `bytearray`

**Example:**
```python
numbers = [1, 2]
numbers.append(3)
```

### Immutable Types
These objects cannot be changed after creation:

- `int`
- `float`
- `bool`
- `str`
- `tuple`
- `frozenset`
- `bytes`

**Example:**
```python
text = "hello"

# Creates a new object
text = text + " world"
```
