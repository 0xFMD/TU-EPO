# Python 101

This content introduces the fundamentals of the Python programming language, starting with basic concepts such as Python setup, data types, and control flow, and continuing through functions and callable objects. Each topic provides clear explanations and practical examples to help beginners build a strong foundation in Python programming.


## Objectives
By completing this course, you will be able to:

- Understand the basic syntax and structure of Python programs.
- Set up and run Python programs successfully.
- Work with Python’s built-in data types and structures.
- Apply control flow statements, conditions, and loops.
- Define and use built-in and user-defined functions.
- Understand Python’s type system and callable objects.
