# Mapping Type (`dict`)

Python provides a built-in **mapping type** called `dict` (dictionary). Dictionaries are used to store data as **key-value pairs**, making it easy to organize and retrieve related information efficiently.


## What is a Dictionary

A dictionary is a data type that stores values using **keys** instead of numeric indexes. The data is stored in the form:
```
key: value
```
Each item consists of:
- a **key**: a unique identifier used to identify the data
- a **value**: the actual stored data

Python dictionaries are created using curly braces { }.

**Example**

```python
student = {
    "name": "Ali",
    "age": 20
}

# Checking the Type
print(type(student))   # Output: <class 'dict'>
```
In this dictionary:
| Key   | Value                |
| ------| -------------------- |
| name  | `"Ali"`              |
| age   | `20`                 |


### Features of Dictionaries

- Mutable (items can be added, modified, or removed after creation)
- Stores data as key-value pairs
- Keys must be unique
- Values can be duplicated
- Can store different data types


## Creating Dictionaries

### Using Curly Braces `{}`

```python
student = {
    "name": "Ali",
    "age": 20

}

print(student)
```

### Using `dict()` 

```python
student = dict( name = "Ali", age = 20)

print(student)
```

### Creating an Empty Dictionary

```python
empty_dict = {}

print(type(empty_dict))
# Output: <class 'dict'>
```

## Dictionary Key Rules

Dictionary keys must be **immutable**.

Valid key types:
- `str`
- `int`
- `float`
- `bool`
- `tuple` (if it contains immutable values)

Invalid key types
- `list`
- `dict`
- `set`

**Example** 

- Valid keys

```python
data = {
    "name": "Ali",
    101: "Student ID",
    (1, 2): "Coordinates"
}
```

- Invalid keys

```python
data = {
    [1, 2]: "Invalid"
}
```

### Duplicate Key

```python
data = {
    "name": "Ali",
    "name": "Sara"
}

print(data)  # Output: {'name': 'Sara'}
```

The second key-value pair replaces the first because dictionary keys must be unique.


## Accessing Dictionary Values

Dictionary values are accessed using their keys.

**Example**

```python
student = {
    "name": "Ali",
    "age": 20
}

print(student["name"])   # Output: Ali
print(student["age"])    # Output: 20
```
> [!important]
> Accessing a missing key causes a `KeyError`.


### KeyError
Attempting to access a key that does not exist raises an exception.

```python
print(student["grade"])    # Output: KeyError: 'grade'
```

### Safe Access with `get()`

The `get()` method retrieves values safely without raising a `KeyError`.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

print(student.get("name"))     # Output: Ali
print(student.get("grade"))    # Output: None
```

You can also provide a default value.

```python
print(student.get("grade", "Not Found"))   # Output: Not Found
```

## Modifying Dictionaries

Because dictionaries are mutable, items can be added or changed after creation.

### Changing Values

```python
student = {
    "name": "Ali",
    "age": 20
}

student["age"] = 21

print(student)  # Output: {'name': 'Ali', 'age': 21}
```

### Adding New Items
A new item can be added by assigning a value to a new key.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

student["major"] = "Computer Science"

print(student)    # Output: {'name': 'Ali', 'age': 20, 'major': 'Computer Science'}
```

## Removing Dictionary Items

### `pop()`

Removes an item using its key.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

student.pop("age")

print(student)  # Output: {'name': 'Ali'}
```

### `del`

Deletes an item completely.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

del student["age"]

print(student)  # Output: {'name': 'Ali'}
```

### `clear()`

Removes all items from the dictionary.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

student.clear()

print(student)  # Output: {}
```

## Useful Dictionary Methods

### `keys()`

Returns all dictionary keys.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

print(student.keys())   # Output: dict_keys(['name', 'age'])
```

### `values()`

Returns all dictionary values.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

print(student.values())   # Output: dict_values(['Ali', 20])
```

### `items()`

Returns all key-value pairs.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

print(student.items())  # Output: dict_items([('name', 'Ali'), ('age', 20)])
```

### `update()`

Adds multiple items or updates existing ones.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

student.update({
    "age": 21,
    "major": "Computer Science"
})

print(student)   # Output: {'name': 'Ali', 'age': 21, 'major': 'Computer Science'}
```

### Dictionary Union Operator (`|`)

The **union operator (`|`)** combines two dictionaries and returns a **new dictionary**.

If both dictionaries contain the same key, the value from the **right-hand dictionary** replaces the value from the left-hand dictionary.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

extra_info = {
    "major": "Computer Science",
    "city": "Riyadh"
}

result = student | extra_info

print(result)   # Output: {'name': 'Ali', 'age': 20, 'major': 'Computer Science', 'city': 'Riyadh'}
```


### Union Assignment Operator (`|=`)

The **union assignment operator (`|=`)** updates an existing dictionary by merging another dictionary into it.

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

student |= {
    "age": 21,
    "major": "Computer Science"
}

print(student)     # Output: {'name': 'Ali', 'age': 21, 'major': 'Computer Science'}
```


> [!important]
> The `|` and `|=` operators were added in Python 3.9. For earlier versions, use the `update()` method instead.

## Dictionary Membership Operators

Membership operators check whether a key exists in a dictionary.

| Operator | Description                          |
| -------- | ------------------------------------ |
| `in`     | Returns `True` if the key exists         |
| `not in` | Returns `True` if the key does not exist |

**Example**
```python
student = {
    "name": "Ali",
    "age": 20
}

print("name" in student)       # Output: True
print("grade" not in student)  # Output: True
```

> [!note]
> Membership operators check keys, not values.
