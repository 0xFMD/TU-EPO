# Python Programming Language 
Python is a high-level, interpreted programming language known for its simplicity and readability. It enables developers to write clear and logical code with fewer lines compared to many other programming languages, and is designed to help programmers work quickly and integrate systems effectively.


## Setup

To start using Python, follow these steps:
1. Download Python
  - Go to: [Python website](https://www.python.org)
  - Download the latest stable version (Make sure to check the box for “Add Python to PATH” during the installation process).
2. Verify Installation
  - Open Command Prompt or Terminal and write:
  ```
  python --version
  # or
  python3 --version
  ```
 - If Python is installed correctly, you will see the installed version number displayed.

3. Choose an Editor / IDE like VS Code or IDLE (comes with Python) to write your code.

## Your First Python Program
After installation, let’s test Python using the `print()` function. The `print()` function is used to display output on the screen.
Open an editor and create a file with a `.py` extension and write the following.

```python
print("Hello, World!")
```

Run the program using the `python fileName.py` command.

Output
```python
Hello, World!
```
### Using `print()` Multiple Times
You can use the `print()` function as many times as you want. Each `print()` statement displays output on a new line by default.


```python
print("Welcome to Python")
print(10)
print(5 + 2)
```

Output
```python
Welcome to Python
10
7
```
>[!Important]
>- Text must be inside single or double quotes
>- Numbers do not need quotes
>- Python automatically evaluates mathematical expressions


## Comments
Before moving to more advanced topics, it is important to understand comments.

Comments are used to:
- Explain code
- Make programs easier to understand
- Leave notes for yourself or other developers
- Prevent certain lines from running (for testing)


### Single-Line Comments
In Python, comments start with the # symbol.

```python
# This is a comment
print("Hello")  # prints Hello
```
> [!Important]
> Anything written after # on that line is ignored by Python.

### Multi-Line Comments
Python does not have a special multi-line comment symbol, but you can write multiple single-line comments:
```python
# This is line one
# This is line two
# This is line three
```

You may also see triple quotes used like this:
```python

"""

This is a comment
written in
more than just one line

"""

```
